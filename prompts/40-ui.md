# 40 — UI agent (wave C)

Read `_common.md` first. Name: `ui`. Branch: `agent/ui`. Run after waves A and B are merged. Runs in parallel with the 3D agent (`50-world3d.md`): you never edit `src/world/*`, they never edit `src/ui/*`.

## Mission
Build all panels, themes, menus and charts. The UI only reads `Game.getSnapshot()` and sends `Game.dispatch(...)`; it never touches state or imports sim internals (pure helper functions excepted).

## Spec chunks you may read
`s00`, `s10` §10.1 (themes and look — skip the art-style 3D details), §10.2, §10.4–§10.9, `s11` §11.2–§11.4, `s11` §11.6 (error panel). Read `src/actions.js` for the action list and `decisions/engine.md` for the snapshot shape. Reference screenshots of real SCADA screens are in the repo root (`SCADA-*.png`, `scada-laview3.jpg`, `inteliscada-*.webp`, `images.png`) for mood only; **do not embed any image file** — the deliverable contains no images.

## Your files
`src/ui/theme.js`, `hud.js`, `popovers.js`, `drawer.js`, `charts.js`, `editor.js`, `modals.js`, `settings.js`, `src/debug.js` (F2 overlay, §10.6), `src/style.css`, `src/main.js` (entry: only wires `Game`, UI, and, if present, the world module; the 3D agent adds its own init call through a documented hook in `decisions/ui.md` — leave a clearly-named `initWorld` optional import point), `tests/ui-smoke.mjs` (see below), `decisions/ui.md`.

## What to build
3 themes (Field Notes default, Brass & Slate, Frosted Dusk) switchable live via CSS variables; layout of §10.2 (HUD, left alerts sidebar, build menu, popovers, SCADA drawer with the hydraulic-grade-line widget, charts with ring buffers of 1,440 points); rule editor (8 slots); new-game screen with terrain-bias menu (§10.5); F2 debug overlay (§10.6); sound toggle (off by default; WebAudio synthesised only, §10.7); save/load menu (§10.8, uses `src/saveload.js` from the tests agent); About screen with the credit line required by §10.9; keyboard and accessibility basics; DOM updates only when a value changes by >0.1 % or 1 s elapsed; popovers/drawer update only while open; canvases handle `devicePixelRatio` and resize.

If a real browser is available to you, also load the bundled file and check the console is clean. Say which you did in the PR.
